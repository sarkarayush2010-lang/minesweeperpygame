# minesweeperpygame

## Description

minesweeper in pygame with 10x10, 20x20, 30x30. detects win/loss, has flags, and times your progress!

made for hack club snek

pretty self explanatory, just run .exe and play minesweeper like normal

## Features
* **Different sizes:** choose from 10x10,20x20 and 30x30 sizes. (i lwk didnt test 30x30 since that took too long for me to solve but the other two work for sure)
* **flags** you can flag mines with a right click for a blue box
* **timer and hud** times you as you solve it. HUD allows you to restart the game or quit to menu anytime


---
## How it works
pretty self explanatory, just run .exe and play minesweeper like normal

Right click for flagging, left click for destroying blocks
